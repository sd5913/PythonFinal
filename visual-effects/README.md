# 深空乱斗 · 独立网页特效包 1.0

这是按确认稿制作的独立 Canvas 2D 特效包，暂未接入 PythonFinal。无需安装依赖、Node.js、编译或网络。完整解压后，用浏览器打开 `demo.html` 即可预览；预览支持四种舰队颜色、1—5号舰船切换和单项/全部重播。

## 文件

- `renderer.js`：确定性绘制函数，包含已确认的六种效果。
- `effects.js`：资源加载、播放、停止、取消、完成通知和清理接口。
- `demo.html`、`demo.js`、`demo.css`：独立预览与四色/编号切换。
- `assets/`：四种颜色共20张舰船原图，以及用户提供的水滴原图。
- `API.md`：接入方式、参数、坐标和回调约定。
- `checks.js`：可在 Node.js 中执行的行为检查：`node checks.js`。
- `VALIDATION.md`：交付验证记录和边界。

## 已确认的视觉行为

| 调用名称 | 表现 |
|---|---|
| `ship_energy_pickup` | 舰体蓝光一闪；不显示能量来源。 |
| `ship_hit` | 数字中心爆出橙黄色火花和闪光；不显示攻击来源。 |
| `ship_collision_destroy` | 两舰在同一点重叠，产生大范围爆炸和约0.32秒震动，之后两舰移除，烟团继续消散。 |
| `droplet_move` | 起点从中心散开蓝白光团，伴随放射光束和碎光；圆头朝前，周身弱柔光，两侧明显长尾迹。 |
| `ship_detected` | 舰体内扫描网格浮现、淡出。 |
| `ship_move` | 舰船沿路径前进，舰尾推进光与短尾迹渐隐。 |

保留原素材配色，不把舰船改成统一颜色。能量光、扫描光等叠加色按确认稿使用蓝青色。舰体从印刷底牌中按轮廓遮罩绘制；原始 PNG 不作修改。水滴原图自带的白色高光和轮廓保留。

## 使用范围

特效包不处理攻击判定、能量扣除、碰撞规则、服务器同步或胜负。`onRemove` 只通知演示或调用方移除对象，不会直接修改游戏数据。未来由服务器确认事件，再由浏览器调用特效。

每个 `Player` 同时播放一个事件，新事件会取消旧事件；多个独立图层可并行播放。接口和效果已经分离，未来接入现有 SVG 棋盘仍需做坐标映射和显示层适配。

素材来源：舰船来自用户指定的 [PythonFinal 仓库](https://github.com/sd5913/PythonFinal)，水滴来自用户附件。素材原作者及授权信息沿用项目组的权属安排，本包不新增素材授权声明。

## 命名约定

特效调用名统一使用小写 `对象_事件`：`ship_energy_pickup`、`ship_hit`、`ship_collision_destroy`、`droplet_move`、`ship_detected`、`ship_move`。代码、预览标识、检查脚本与说明使用同一名称。公共文件 `effects.js`、`renderer.js` 保留原文件名；`assets/` 中的图片名称保留，图片名不属于特效调用名。
